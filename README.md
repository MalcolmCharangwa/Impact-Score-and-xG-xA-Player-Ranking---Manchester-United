# Football Data Analytics - Python

This repository showcases a practical exploration of football data analytics using Python. The project focuses on collecting football data, analyzing player performance across a season, and assessing whether players over- or under-perform relative to expected goals and expected assists. Drawing on a Manchester United-focused dataset, the work demonstrates a structured workflow that includes data acquisition, cleaning, exploratory analysis, and insight generation.

## Project Overview

This project reflects an applied approach to sports analytics, combining data collection and statistical interpretation to better understand player contributions. It is designed to highlight core analytical thinking, from sourcing data to generating meaningful football performance insights.

## Key Focus Areas

- Data collection and preparation
- Player performance analysis
- Expected goals and expected assists evaluation
- Exploratory data analysis with Python

## What This Repository Demonstrates

The repository serves as a portfolio-style example of how Python can be used to explore football data in a clear, analytical, and reproducible way. It emphasizes hands-on analysis and the ability to turn raw football statistics into interpretable insights.
